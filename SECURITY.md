# Security Policy

## Supported Versions

Security fixes are applied to the latest release and the current `main`
branch. Older releases may not receive backports.

## Reporting A Vulnerability

Use GitHub's private vulnerability reporting form in the repository Security
tab. Include the affected edition, reproduction steps, impact, and any safe
proof-of-concept material. Do not open a public issue for an unpatched
vulnerability.

You should receive an initial acknowledgement within seven days. Validation,
fix, and disclosure timing depend on severity and reproducibility. Reports that
only describe general code-quality concerns can use a normal GitHub issue.
